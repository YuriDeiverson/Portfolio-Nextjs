Portfólio Pessoal - Desenvolvedor Fullstack
Este é meu portfólio pessoal criado com React, Next.js, Tailwind CSS e animações com Framer Motion. A aplicação tem como objetivo apresentar minhas habilidades, projetos, ferramentas utilizadas e um meio de contato direto.

✨ Tecnologias Utilizadas
Next.js – Framework React moderno com foco em performance.

React – Biblioteca JavaScript para construção de interfaces.

Tailwind CSS – Framework CSS utilitário para estilização rápida e responsiva.

Framer Motion – Biblioteca de animações para React.

Web3Forms – Integração de formulários via API para envio de mensagens.

🔍 Funcionalidades
Sobre mim – Sessão com descrição pessoal e lista de habilidades e ferramentas.

Projetos – Lista visual com os principais projetos desenvolvidos (com links externos).

Serviços – Sessão com minhas áreas de atuação (em construção).

Contato – Formulário funcional com integração ao Web3Forms para envio de mensagens.
